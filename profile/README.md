<h2 align="center">Aliquome</h2>

<p align="center"><b>An exact aliquot of every bioinformatics database: the precise release, one link away.</b></p>

Aliquome is an open, free atlas for reproducible bioinformatics. It is rebuilt every two days on GitHub Actions and served from GitHub Pages.

- **Databases:** 794 releases of 83 core resources (GRCh38, T2T-CHM13, Ensembl, gnomAD, UniProt, AlphaFold DB, ChEMBL, GTEx, CELLxGENE and more), each with a versioned link and download code for curl, Python, R, `pooch`, AWS CLI and `gcloud`.
- **Datasets:** 519 machine-learning-ready biology datasets with loaders and download code.
- **Benchmarks:** 200 results tables with 1,854 published results; re-rank them, open any model or paper, and propose changes for review.
- **Papers:** the newest papers from 22 leading bioinformatics and computational biology journals, sorted by field.
